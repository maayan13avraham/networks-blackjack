# Blackjack Simulation (Python)

This project implements a simplified Blackjack game simulation using Python.  
It includes a client-server architecture that communicates using TCP sockets.

## Project Overview

The system simulates a Blackjack game between a player and a dealer using a custom communication protocol.

Main components:

- **server.py** – manages the game logic and dealer behavior
- **client.py** – represents the player and sends requests to the server
- **protocol.py** – defines the communication protocol between client and server

## Features

- Blackjack game logic implementation
- Client–server communication using TCP sockets
- Custom message protocol for game actions
- Separation between networking and game logic

## Technologies

- Python
- TCP sockets
- Client–Server architecture
